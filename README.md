# 🎮 儿童模拟器

给小朋友玩的浏览器 3D 碰撞模拟游戏，基于 Three.js。

## 包含两个游戏

| 游戏 | 说明 | 启动方式 |
|------|------|----------|
| 🚗 **城市碰撞模拟器** | 驾驶汽车穿越无限城市，与 NPC 碰撞 | 直接打开 `car_game/index.html` |
| 🚂 **火车大冒险** | **全新重写！** 高架铁路网上飞驰、变轨、收集星星 | `npm run train` 后访问 |

## 快速开始

### 🚗 城市碰撞模拟器（旧，无需构建）

直接用浏览器打开 `car_game/index.html` 即可。

### 🚂 火车大冒险（新，Vite 构建）

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run train
```

然后浏览器访问 http://localhost:3000/train-game/index.html

## 技术特点

### 🚗 城市碰撞模拟器（旧）
- **Three.js r134** 3D 渲染，无构建工具
- **无限地图**：程序化街区生成，按玩家位置加载/卸载区块
- **物理系统**：Arcade 操控 + 漂移/抓地 + 碰撞损伤分级
- **AI 交通**：NPC 车辆自主行驶、红绿灯响应、跟车距离
- **特效系统**：火花/烟雾/火焰/碎片粒子、屏幕震动、碰撞闪屏
- **无外部素材**：所有 3D 模型均为程序化生成

### 🚂 火车大冒险（全新）
- **Three.js (npm)** + **Vite** 构建
- **CatmullRomCurve3** 平滑轨道系统，含 3 条分支岔路
- **真实 3D 火车模型**：复兴号风格车头 + 多节车厢 + 连接杆
- **变轨系统**：接近岔路口提示 ←→ 选道，进入分支景观
- **程序化场景**：山川、树林、湖泊、车站
- **收集系统**：轨道旁金色星星，旋转发光
- **NPC 列车**：对向行驶，碰撞触发火花/烟雾/火焰特效
- **第三人称/俯视视角** 切换（V 键）

## 操作

### 🚗 城市碰撞模拟器
| 按键 | 操作 |
|------|------|
| W/↑ | 油门 |
| S/↓ | 刹车/倒车 |
| A/← | 左转 |
| D/→ | 右转 |
| 空格 | 手刹漂移 |
| V | 切换视角 |
| F | 触发事故 |
| 鼠标拖拽 | 旋转镜头 |
| 滚轮 | 缩放 |

### 🚂 火车大冒险
| 按键 | 操作 |
|------|------|
| W/↑ | 加速 |
| S/↓ | 刹车/倒车 |
| A/← D/→ | 岔路口选道 |
| 空格 | 急刹车 |
| V | 切换视角（第三人称/俯视） |

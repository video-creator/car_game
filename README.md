# 🎮 儿童模拟器

给小朋友玩的浏览器 3D 碰撞模拟游戏，基于 Three.js，纯前端无需构建。

## 包含两个游戏

| 游戏 | 说明 |
|------|------|
| 🚗 **城市碰撞模拟器** | 驾驶汽车穿越无限城市，与 NPC 车辆碰撞制造车祸 |
| 🚂 **火车碰撞模拟器** | 控制火车在复杂路网上行驶，变轨、追尾、脱轨 |

## 快速开始

直接用浏览器打开 `car_game/menu.html` 或任意游戏页面。

## 技术特点

- **Three.js r134** 3D 渲染，无构建工具
- **无限地图**：程序化街区生成，按玩家位置加载/卸载区块
- **物理系统**：Arcade 操控 + 漂移/抓地 + 碰撞损伤分级
- **AI 交通**：NPC 车辆自主行驶、红绿灯响应、跟车距离
- **特效系统**：火花/烟雾/火焰/碎片粒子、屏幕震动、碰撞闪屏
- **音效**：Web Audio API 合成的引擎声和碰撞声
- **无外部素材**：所有 3D 模型（汽车、火车、建筑）均为程序化生成

## 操作

### 城市碰撞模拟器
| 按键 | 操作 |
|------|------|
| W/↑ | 油门 |
| S/↓ | 刹车/倒车 |
| A/← | 左转 |
| D/→ | 右转 |
| 空格 | 手刹漂移 |
| V | 切换视角（第三人称/第一人称） |
| F | 触发事故 |
| 鼠标拖拽 | 旋转镜头（第三人称） |
| 滚轮 | 缩放 |
